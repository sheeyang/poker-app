# Treat Analysis as Derived Data

Table Session Records retain authoritative replay inputs, while Policy distributions, Decision Scores, and related analysis are versioned derived results. Analysis may be cached using the Table Session, Participant, Hand, Decision, frozen input fingerprint, Reference Strategy implementation versions, configurations, effective evaluation and selection seeds, and scoring method as its identity, but it can always be discarded and recomputed with a newly selected reference without rewriting poker history.

Shared decision-score and arithmetic-mean summary computations belong to `packages/research`. The server owns job scheduling, cached-result lookup, and tracking the required analyses' outcomes; Research computes plain numerical results from the supplied successful analyses, and the frontend presents scores and readiness/error states without maintaining a second scoring implementation. Missing or unsuccessful required results cannot be passed off as a complete set for summary computation.

M2 includes backend individual-decision results and Hand and Table Session summaries; overall-history summaries remain M6 scope. Its analysis uses request-driven cache lookup and queued/running job deduplication without guaranteed background completion or durable job obligations, as established in [ADR-0026](0026-retain-numerical-trainer-analysis-independently-of-gameplay.md). Every new request captures the currently selected Reference Strategy; accepted human actions retain no Reference Strategy assignment. Each summary freezes its included decision IDs and one complete Reference Strategy for the whole set, and returns the captured poker revision and decision count. Product presentation and request timing belong to M3, without requiring a session-ending lifecycle in M2.

A hand, session, or history summary displays its final arithmetic-mean scores only after all required decision analyses have succeeded. Pending or running required analysis is represented by `Analyzing`, and failed required analysis by `Error`; missing, running, and failed results never contribute zero or produce a partial summary score.

`Error` takes precedence when any required analysis has failed, even if other jobs are running; an explicit Retry must succeed before a final score can appear. The HTTP get-or-start operation schedules missing analyses through JobRunner, reuses matching successful cached results and queued/running jobs, and returns existing failures without restarting them. Explicit Retry retries only failed analyses, preserves their inputs and seeds, and reuses successful results and active jobs. Selecting a new Reference Strategy or configuration establishes a new analysis request. A summary with no human decisions has no backend numerical score or scheduled jobs; its eventual presentation shows `—` and `No decisions`.

Use HTTP for get-or-start, explicit Retry, and fetching numerical results and summary averages. Completion/failure notifications arrive through the shared browser WebSocket's automatically enabled authorized user channel, independently of live table subscriptions, and relevant notifications trigger HTTP refresh without polling. Successful results are persisted and readable before completion notification; failure state is recorded before failure notification. After user-channel readiness on both initial connection and reconnect, HTTP refresh reconciles relevant analysis with successful persistent results and transient job/failure state. Failure states may disappear on server restart, after which a request treats the analysis as missing and schedules it.

The primary Hand, session, and overall-history aggregate is the arithmetic mean of human Decision Scores; the secondary aggregate is the arithmetic mean of their Action Rank Scores. Review uses the currently selected Reference Strategy, implementation versions, and configurations, not an originally stored distribution or score. Reuse a cached result only when its full analysis identity matches, so improved or newly selected Strategies can reanalyze historical decisions without changing the accepted poker commands.
